### 关键结论

- **③ 根因**：挂件层是**普通顶层窗**（只是被按 Z 序插在桌面窗正上方），不是桌面的子窗口 ⇒
  Win+D「给所有顶层窗发最小化」照样把它最小化掉。**没有走 `SetParent`**（会让坐标体系变成相对父窗，
  且 Explorer 重建 WorkerW 时连带我们），改为轮询判 `IsIconic` → `SW_SHOWNOACTIVATE` 还原 →
  重贴回桌面层。用户说的「点显示后马上显示又消失」是「最小化 + 显示 + 驻留重建」三件事叠加，一并消除。
- **④ 根因**：挂件窗平时 `ignore_cursor_events(true)`，能不能点到完全靠 Rust 按全局光标位置判定 ⇒
  **离散采样追不上连续移动**。轮询 60ms → **25ms**，命中区四边各外扩 `HIT_PADDING = 4px`。
  缩放补齐 **8 向**（原来只有 se），边手柄两端各留 12px 给角手柄（否则角上同时命中边和角，方向会跳），
  `n`/`w` 边缩放要**同时移动原点**。
- **① 是用户改口**：V34 要求「便签也一个吧」，V35 要求「便签应该可以添加多个」⇒
  「同类唯一」只保留在日历上。便签自动命名 `便签` / `便签 2` / `便签 3`…（第 1 个不带编号）
  并轮流给不同配色；标题栏加调色盘（7 档，落库 `grid_boxes.accent`）+ 双击重命名提示。
  同时补 `raiseBox`（交互开始时 `sort = max(sort)+1`，只在拖动/缩放开始时抬，不做「点一下就抬」）。
- **② 的做法**：默认尺寸 320×300 → **360×430**；日期格改 3 行（公历日 / 农历·节气·节日 / 标记行：
  计划=琥珀圆点、生日=🎂），休班改右上角小角标；挂件卡片改**深色磨砂**
  （`rgba(12,14,22,0.62)→0.46` 渐变 + 顶部 1px 高光 + 大柔影，**不加硬边框**）。
  自动撑高走 `scrollHeight` 上报 + `autoHeightBlockedRef`（记「手动缩放那一刻的内容高度」，
  内容真变了才重新接管），上限 `innerHeight × 0.7`。

### ★ 根因（靠用户机上的现场日志钉死，不是猜的）

`%LOCALAPPDATA%\Handy\grid-debug.log` 里，11:54:48–11:56:33 **连续 90 多行完全相同**：

```
Z 序错位（连续两次；我正下方不是桌面窗口），重新贴回桌面层（overlay=0x4007a8 host=0x1015a below=0x708d4）
```

⇒ **每次自检都失败、每次都重排一次**，闪烁就是这个循环本身。判据要求
`GetWindow(hwnd, GW_HWNDNEXT)` **正好**是桌面窗口，但**桌面正上方那一格是公共地段**：
把 681 个顶层窗完整列出来后看到，**搜狗输入法的 6 个隐藏助手窗**（`SoPY_Hint` / `SoPY_UI` /

`below=0x708d4 / 0x2f0b72 / 0x1035a` 正是它们。判据于是**永远不成立**。
V35 把轮询 60→25ms，让 `REASSERT_TICKS=40` 的含义从 2.4 秒变成 1 秒，把「偶尔闪」放大成「一直闪」。

### 修法（三重保险）

1. **判据放宽**：`ZVerdict` 改成**有界下探**（往下最多走 24 层，能碰到桌面就算对；只有「走到底没碰到」
   = 压在桌面下 / 「走满没碰到」= 顶得太高 才纠正）；
2. **节奏改时间量**：`REASSERT_TICKS`（周期数）→ `REASSERT_INTERVAL_SECS = 3`（秒）——
   轮询周期是手感参数，不该顺手改掉自愈节奏；
3. **保险丝**：连续纠正 `REASSERT_MAX_FIXES=5` 次就退避 `300` 秒（只记一次日志）。
   用户「隐藏→显示」时 `reset_reassert_state()` 复位。

### 先做的事故取证（不猜，只量化）

写了 `.tmp/v37/scan-legacy.py`（只读 `os.scandir` 显式栈，避免深路径递归爆栈）扫桌面：

- 最深路径形状：`桌面\Handy整理\新格子 1\Handy整理\新格子 1\…` 重复约 1000 次
  ⇒ **一目了然是「自复制」**，不是「多跑几次各多一层」（否则体量会逐份递增，而 5 份几乎一样大）。
- 一级子目录同时有 `其他/压缩包/图片/安装包/文档`（organizer 产物）与
  `文件夹/新格子 1/3/4`（grid 产物）⇒ **两个功能都在往里搬**。

**根因**（读代码 + 路径形状互证）：`move_with_conflict_rename` 在 `fs::rename` 失败后走
「递归复制 + 删源」兜底，而 `copy_dir_recursive` 是**先 `create_dir_all(dest)` 再 `read_dir(src)`**；
dest 落在 src 内部时，遍历会看见刚建出的目标并继续递归 ⇒ **一次调用就无限自复制**，
一路顶到路径长度上限（1001 层）。

### 修法（三层）

1. **模型换回「呈现层」**：`grid_item_add` / `grid_item_delete` / `grid_item_move` /
   `auto_arrange_inner` 全部改成**只改登记、不动文件**；新的 `register_item` 是唯一写入口
   （幂等 + 尊重「不要它」名单 + 归属唯一）；`list_registry_items` 被 `list_live_items` 取代
   （只做存在性校验并清理失效登记，不再按磁盘目录对账）；`reconcile_all_boxes` 去掉
   root 参数。
2. **护栏**：`is_storage_entry(name)` 改**前缀匹配**（`Handy整理*` / `Handy收纳*`，不再路径全等，
   V36 就是全等判漏了容器自身）；`move_with_conflict_rename` 第一行加
   「**拒绝把目录移动到它自己里面**」（`normalize_path` + `starts_with`）。
3. **迁移 v9**：`grid_boxes.category`（显式记类别，改名不丢映射）+ `DELETE FROM grid_items`

## V38 批次（承接 V37 装机验收后的三张截图反馈）

用户反馈原文要点：① 新加的格子默认被锁定、不好操作；② 格子会莫名消失、找不到规律；
③ 点「整理桌面」后格子乱建更乱（没有按桌面算过的流布局），且桌面原图标没消失 ——
「相当于桌面又两个相同的内容了」。

### 三条反馈的根因（都有确定的代码位置，不是玄学）

| # | 症状 | 根因 |
| --- | --- | --- |
| ① | 新格子建完拖不动 | `editMode` 默认 false，`addBox` 建完不解锁；叠加下面的空滤后新格子可能直接隐身 |
| ② | 格子「动不动就不见了」 | `visibleBoxes = boxes.filter(...itemCount>0)` —— 空格子不占位；**v9 迁移清空 grid_items 后所有 folder 格同时满足条件 ⇒ 集体蒸发**（管理页里它们还在） |
| ③a | 整理后很乱 | 旧排布按「已有格子个数」套固定步进 + 假定统一尺寸 + **只摆新建格子**（旧格子留当年坐标）+ **不拿工作区高度**（纵向排出桌面外） |
| ③b | 桌面两份内容 | V32 起不再自动隐藏原生图标，而 V37 已改成引用呈现 ⇒ 同一批文件显示两遍 |

### 这次的做法

- 抽 **`FlowPlacer`**：靠右起、一列内自上而下、每个格子用自己的宽高、便签/日历当禁区必须让开、
  最多 8 列有界、排不下返回 `None` 而不是叠压。一键整理与「新建格子」落点**共用同一套**。
- 整理 = **全量重排**（`layout_all_boxes`），挂件位置不动但作禁区。
- **接管桌面呈现**：`grid_meta.desktop_takeover` 存偏好 + `grid_takeover_set/get`；
  收起挂件/退出**立刻归还**图标；工具栏按钮是手动出口；隐藏失败要**如实提示**。
- 接管后必须补回被接管的入口：`ensure_system_box`（此电脑/回收站/用户文件夹，CLSID `::` 虚拟条目，
  `list_live_items` 对 `::` 前缀豁免存在性校验）。
- `.lnk` 由「跳过」改为归进**「快捷方式」格** —— 旧规则只在「原生图标还在」的前提下成立，
  接管之后跳过它，用户的程序快捷方式就没有入口可点了。
- 前端：`visibleBoxes` 取消空滤、`focusNewBox`（新建→解锁+2.4s 高亮）、工具栏加 ✨整理桌面
  与 Monitor 接管开关、`TakeoverState` 类型与 IPC。
- `grid_box_delete` **不再删磁盘目录**；顺手删掉 V33 遗留的 `storage_root` 等一堆死代码。
- 修正 `GridManagerView` / `OrganizerView` 里两处过期文案（「跳过的是快捷方式」→「历史收纳容器」）。
