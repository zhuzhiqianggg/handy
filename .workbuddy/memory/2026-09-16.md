### 2. `platformOf()` 的关键细节（回归重点）

**不能粗筛 `/[LW#]/`** —— 月份别名 `JUL` 含 `L`、星期别名 `WED` 含 `W`，粗筛会把最普通的
`0 9 * * WED` 误报成「Quartz 专用」。假警报会让人开始无视提示，比不提示更糟。
实现按「逗号切分后的**整段**」精确匹配 `L` / `5L` / `15W` / `1#2`。
另：未知宏（如 `@everyday`）原先返回 `form:'standard'` 导致不报警 → 改回 `'macro'`。

### 3. 文本处理台（Phase 1）

- 逻辑全在 `src/lib/textlab.ts`（纯函数，无 React/DOM），界面 `TextLab.tsx` 只收参显示。
  `LINE_OPS` 是**数据驱动表**（20 项 / 5 组），`applyLineOp` 是唯一 switch —— 新增行操作 = 加一条数据 + 一个分支，界面与回归自动覆盖。
- **换行风格必须全程带着走**：切行统一吃 `\r\n` / `\r` / `\n`，拼回按原风格还原。
  直接 `split('\n')` 会在 Windows 文本行尾留 `\r`，于是「去重」把 `a` 和 `a\r` 当成两行 —— 这类工具最经典的假 bug。
- 界面是**就地改写 + 30 步撤销栈**，不是「左输入右输出」：本机窗口最小 640px，左右分栏各挤一半；
  真实用法是「粘贴 → 操作 → 复制」，中间态没有保留价值。
- 四个页签：查找替换 / 行处理 / 列与包裹 / 统计与换行。带示例条（Nginx 日志、IP 列表、SQL IN、正则提取 IP）。

### 4. 响应式审计：把「口头要求」变成可复跑工具

`scripts/audit/layout-audit.mjs`：起 vite dev server + 无头浏览器，对 **24 工具 + 3 模块页 × 3 档视口
（680 / 1024 / 1680）** 实测四个指标 —— `ox`/`mox`（横向溢出）、`clipX`/`clipY`（**内容溢出但不滚**）、
`overlap`（**非祖孙块级矩形相交**）、截图。

**关键认知：只看溢出会漏掉所有真缺陷。** V23 抓到的两处，`ox` 全程为 0：

1. `CalendarPanel` 的 42 格网格挂 `flex-1` → 窄窗口下被压进「剩余高度」，680px 时日历只显示到 **20 号**；
2. `PlanPanel` 的 `min-h-0` 被上排 `flex-1` 挤成 **19px 空壳**（外层 `overflow-y-auto` 的滚动条根本没机会出现）。

**统一修法**：`lg` 以下一律单栏、各面板按内容高度排布、滚动交给外层内容列；
一切 `flex-1` / `min-h-*` 加 `lg:` 前缀关进宽屏。复跑 **30 页面 × 3 视口 = 0 溢出 / 0 裁切 / 0 重叠**。

> **flexbox 教训（与 V22 §1.8.1 是一体两面）**：`flex-1`（`flex-basis: 0%`）在**auto 高度父容器**里
> 不是「撑满」而是「可被压缩到 0」。要撑满必须给父级明确高度；给不了就内容自然排布 + 外层滚动。

### 5. 踩到的坑

- **TS1005**：`cron.ts` 里给 `platformOf()` 写中文说明时，模板字符串里带**反引号**（`` `L` 最后一天 ``）
  和 markdown `**` → 解析器直接崩。写进源码的中文化说明一律**不用反引号、不用星号**。
- **回归里算错的期望值比产品代码更危险**：textlab 首轮 128 PASS / 8 FAIL，全是**我自己的期望值写错**
  （`hello world\n第二行 abc` 应是 19 字符 / 25 字节 / 最长 11；`wrapLines` 有 min-width 10；
  `keep-matching` 正确排除 WARN 所以是 2 不是 3）。核对期望值要逐字符数，别凭直觉。
- **V21/V22 关于 `clean-dist.mjs` 的结论再次修正**：阈值确实存在，但 `clean-dist.mjs` **不是错的路子**，
  错的是「不带上限一路删」。V23 给它加了 `--max=N`（单回合上限）+ `exit 2 = 还有剩余`；

  结论：优先单独 build；真要逐文件清就 `--max=40` 分回合。

### 4. 踩到的坑

- **迁移脚本的自检条件被自己的改动污染**：判断「文件里是否已 import」时用的是替换后的行，

  `tsc` 报 86 个 `Cannot find name`。教训：**校验条件要盯"独立的证据"（如 import 行开头），别盯刚被改写过的位置。**

  删结构化文本前先数清块的首尾行，删完立刻 `tsc`。
