### 2. `platformOf()` 的关键细节（回归重点）

**不能粗筛 `/[LW#]/`** —— 月份别名 `JUL` 含 `L`、星期别名 `WED` 含 `W`，粗筛会把最普通的
`0 9 * * WED` 误报成「Quartz 专用」。假警报会让人开始无视提示，比不提示更糟。
实现按「逗号切分后的**整段**」精确匹配 `L` / `5L` / `15W` / `1#2`。
另：未知宏（如 `@everyday`）原先返回 `form:'standard'` 导致不报警 → 改回 `'macro'`。

### 3. 文本处理台（Phase 1）

- 逻辑全在 `src/lib/textlab.ts`（纯函数，无 React/DOM），界面 `TextLab.tsx` 只收参显示。
  `LINE_OPS` 是**数据驱动表**（20 项 / 5 组），`applyLineOp` 是唯一 switch —— 新增行操作 = 加一条数据 + 一个分支，界面与回归自动覆盖。
- **换行风格必须全程带着走**：切行统一吃 `\r\n` / `\r` / `\n`，拼回按原风格还原。
  直接 `split('\n')` 会在 Windows 文本行尾留 `\r`，于是「去重」把 `a` 和 `a\r` 当成两行 —— 这类工具最经典的假 bug。
- 界面是**就地改写 + 30 步撤销栈**，不是「左输入右输出」：本机窗口最小 640px，左右分栏各挤一半；
  真实用法是「粘贴 → 操作 → 复制」，中间态没有保留价值。
- 四个页签：查找替换 / 行处理 / 列与包裹 / 统计与换行。带示例条（Nginx 日志、IP 列表、SQL IN、正则提取 IP）。

### 4. 响应式审计：把「口头要求」变成可复跑工具

`scripts/audit/layout-audit.mjs`：起 vite dev server + 无头浏览器，对 **24 工具 + 3 模块页 × 3 档视口

`overlap`（**非祖孙块级矩形相交**）、截图。

**关键认知：只看溢出会漏掉所有真缺陷。** V23 抓到的两处，`ox` 全程为 0：

1. `CalendarPanel` 的 42 格网格挂 `flex-1` → 窄窗口下被压进「剩余高度」，680px 时日历只显示到 **20 号**；

**统一修法**：`lg` 以下一律单栏、各面板按内容高度排布、滚动交给外层内容列；
一切 `flex-1` / `min-h-*` 加 `lg:` 前缀关进宽屏。复跑 **30 页面 × 3 视口 = 0 溢出 / 0 裁切 / 0 重叠**。

> **flexbox 教训（与 V22 §1.8.1 是一体两面）**：`flex-1`（`flex-basis: 0%`）在**auto 高度父容器**里
> 不是「撑满」而是「可被压缩到 0」。要撑满必须给父级明确高度；给不了就内容自然排布 + 外层滚动。

### 2. 密码：符号不连排要「构造」，不能「修补」

- **先合并重复实现**：组件内联那份与 `@/lib/passwordGen` 各有一套近似逻辑（V24 遗留）→ 删内联（−5576 字符），
  只留 `passwordGen.ts`。**同一份逻辑写两遍，改一处只治好一半。**
- 默认符号占比 **100% → 25%**，界面新增「符号不连续」开关（默认开）。
- 「不连排」若用「生成后扫一遍、发现连排就换位置」实现 → **死循环 + 取值偏置**。
  改用性质构造：**可用槽位按奇偶分两组，只从一组抽样 → 结果两两必不相邻**（可证、无循环、无偏置）。
- 容量上限 `separatedCapacity(n) = ceil(n/2)`：40 位想塞 20 个符号**做不到**（首尾被占后只剩 38 个候选位，
  同奇偶最多 19）→ **收敛并在 notes 里说明原因**，绝不悄悄少给。
- 回归 86 条，期望值用**独立公式**表述（`expectedSymbols = min(max(1, floor(len·ratio)), separatedCapacity(len−2))`），
  不复述实现 —— 否则实现错了测试跟着错。

### 3. 正则库：实测 16/30 条零命中

- 根因是**语义错配**：一批「整串校验」（`^…$`）条目配了**多行样本文本** → 永远不可能命中。

### 3. 修掉的 6 处真缺陷（全部先写失败断言、再改实现）

最高危的一类是「**不报错、只给错答案**」——用户看不到任何异常，只会得到一个错的结果：

1. **URL「主机:端口 被当成协议」**：`new URL('example.com:8080/path')` 把 `example.com:` 当协议、
   `8080/path` 当路径 → hostname/port 双双为空。`localhost:5173` 是本地调试最常见写法。
   修法：`looksLikeHostPort()`（冒号前含 `.` 或冒号后直接跟数字 ⇒ 是 host:port），补 `http://` 再解析。
2. **协议相对写法 `//host/path`** 被补成 `http:////host/path` → 只补协议名。
3. **`buildUrl({protocol:'https://'})`** 拼出 `https://://a.com` → 归一化 `replace(/[:\/]+$/,'')`。
4. **`FileSize` 切进制单位不跟走**：`unitFactor` 查不到就返回 1 ⇒ **1.5 TiB = 1.5 字节**（差 1024⁴ 倍），
   且 `<select>` 显示项与实际算法单位对不上。修法：抽出 `src/lib/byteUnits.ts`（两表按下标对齐）+
   `toMatchingBase()` 带单位走 + `toBytesText` 内部再归一（**API 边界自愈**）。
5. **JSON→TS 接口名复用只看键名**：`{item:{a:1}}` 与 `{wrap:{item:{a:'s'}}}` 第二处**静默复用** `a: number`
   —— 生成的类型与数据打架。修法：签名加入 `kindOf(values)`（粗粒度类型标签），不同结构才复用；
   顺带把序号递归改成 `while` 找空位（旧版第三次冲突会产出 `Item22`）。
6. **`parseJsonPath` 把不支持的语法当字段名**（`[?(@.price<10)]`、`[0:2]`）→ 安静返回 0 命中，
