### 最高优先级：桌面挂件「几乎没实现」的根因（反馈 #9/#4）

报错 `Wrong number of parameters passed to query. Got 1, needed 0`。
根因在 `src-tauri/src/commands/grid.rs`：`next_sort(conn, sql, 0)` 对**不含 `?` 占位符**的 SQL
（`SELECT COALESCE(MAX(sort)+1,0) FROM grid_boxes`）仍绑定 1 个参数 → 每次 `grid_box_upsert`
与 `grid_item_add` 都失败，挂件因此完全没有能力。
**修法**：签名改 `fn next_sort(conn, sql, bind: Option<i64>)`——`None` 走 `query_row(sql, [])`，
`Some(v)` 走 `params![v]`；级联位置改用 `existing.count`（不再用 `timestamp_millis`）。
**教训**：rusqlite 的参数个数必须与 SQL 占位符严格一致；无占位符就传空数组，别传 `0`。

### RichMarkdown 的 6 个内核坑（**只有逐字符输入才暴露**，整串注入测不出来）

| # | 现象 | 根因 / 修法 |
| --- | --- | --- |
| 1 | 敲完 `**粗体**` 继续打字仍延续加粗，`*斜体*` 叠成 `***斜体***` | 光标落点：`setStartAfter(el)` 与哨兵节点 offset **0** 都会被 Chrome 判为「紧邻前一个行内元素」而续样式 → 必须落在哨兵内 **offset 1** |
| 2 | 光标被并回 `<strong>` | `createTextNode('')` 做锚点会被浏览器选区规范化**回收** → 改用零宽空格 `ZWSP` 哨兵，序列化时统一剥掉 |
| 3 | `**粗体**` 退化成斜体 | 逐字输入时第 5 个 `*` 先命中单星号规则把 `*粗体*` 变 `<em>` → 斜体规则加 `(?<!\*)` 断言 |
| 4 | 空 `<h1>` 把光标挤回上一行，后续文字跑进上一段 | `placeCaretAtEnd(空元素)` 无效 → 新块一律带零宽种子（`withCaretSeed`） |
| 5 | 新笔记第一笔 `# ` 永远变不出标题 | 内容裸挂在根节点时没有块元素可替换 → `wrapInlineRunAtCaret` 先包一层 `<div>`；**`appendChild` 搬动节点会让浏览器把选区重置到容器开头**，必须手动保存/还原光标 |
| 6 | `^#\s$` 永不匹配 / 空标题残留 `#` | `marker` 先 `stripZwsp`；标题内容为空时不再输出 `#` |

已知取舍：**列表项内部**敲 `> ` / `# ` 不做块级转换（列表项非顶层块，替换会破坏 `<ul>`）。
ZWSP 哨兵会留在 DOM 里（序列化已剥离，数据无污染），长文档会累积，暂未清理。

### 工具坑（V19 新增，务必记牢）

- **`agent-browser keyboard type` 不能用来测逐键行为**：它走整串 `insertText`，实测 `'# '` 落进编辑器
  变成 `NBSP + #`，还会凭空多出 `*`（`'# '` → `"# *"`），完全是假的失败信号。
  逐键场景必须用 `eval` + `document.execCommand('insertText', false, ch)` 循环。
- **读 React 状态前必须 `await` 一个 tick**：在同一个同步块里 type 完立刻读
  `<pre data-testid="md-source">` 会永远是**上一帧**（React 18 批处理 + microtask flush），
  会误导成「onChange 没触发」。驱动写成 async IIFE 并在每步 `await new Promise(r=>setTimeout(r,0))`。
- `agent-browser` 的静态服务**必须与冒烟命令在同一条 bash 调用里启动**，否则后台进程被作业对象回收，
  下一条命令只会拿到 `ERR_CONNECTION_REFUSED`。
- 诊断 DOM 事件类问题时，把输出里的 `\u200B` / `\u00A0` 显式替换成 `<Z>` / `<N>` 再打印，
  否则零宽字符在日志里完全隐身，根本看不出光标锚点在哪。

### 本轮新增的工具坑

- **`display: contents`** 可让包装层不生成盒子、子元素直接参与父级 flex —— 用来「同一份 JSX 同时服务
  折叠态（单行 flex-row）与展开态（flex-col）」非常干净；但不要依赖 Tailwind `flex` 与 `contents`
  的 CSS 顺序取胜，直接二选一写死 className。
- **Tauri 里程序性改窗高**：`resizable(false)` 只拦用户拖拽，`win.set_size()` 照常生效；
  但 Windows 以中心为锚点拉伸，改高后必须紧跟着 `set_position()` 才能保持「顶部居中」。
- **量高壳必须 auto height**：把 `h-full` 的节点高度报给 Rust 会形成
  「窗口高 → 量出窗口高 → 再设窗口高」的自激循环；外套一层 `w-full` 自动高度容器即可。
